# Chat Ping

Клиентский Fabric-мод: СКМ по блоку — метка видят все на сервере, без серверной части.

Транспорт — обычное чат-сообщение вида `Ping at {x*10}, {y*10}, {z*10}` (координаты
умножены на 10 для неочевидности — не защита, просто не кидается в глаза). Без
невидимых символов: тест показал, что сервер может принять их за попытку
эксплойта/флуда. См. `ТЗ.md` для полного описания и `dev.chatping.ping.PingCodec`
для формата.

## Сборка

```
./gradlew build
```

Собранный jar — в `build/libs/`.

## Текущий статус

MVP под Minecraft 1.21.1 (Fabric, Yarn mappings). Поддержка диапазона 1.21.1–1.21.11
через Stonecutter — следующий шаг, после проверки, что ядро (raycast → кодирование →
рендер) работает в игре.
